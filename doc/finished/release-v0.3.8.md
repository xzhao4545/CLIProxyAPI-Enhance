# Release v0.3.8

The server advances its local fork version from `0.3.7` to `0.3.8`, tagged
`v0.3.8`. The paired management panel advances from `0.3.3` to `0.3.4`, tagged
`v0.3.4` in its own repository. These versions follow the fork's release line.

and the corresponding management editor. The panel integrates upstream UI
changes while retaining Enhance usage statistics, unavailable credentials and Amp.

Validation: Go formatting and server compilation passed. The panel production
build passed with `VERSION=v0.3.4`. Version metadata and release tags agree.
